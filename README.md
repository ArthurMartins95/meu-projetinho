## HTML para a iniciantes

## Objetivo
Mini Curso sobre os Fundamentos Básicos do HTML e CSS


## Público Álvo
Focado para Iniciantes

## Pré-requisitos
- Ja ter conhecimento prévio dos conceitos de algoritmos (Ex:Estrutura básica, Função e etc.)
- Ter o VSCODE instalado na máquina

## Como Navegar

1. Comece pelo módulo de introdução ao HTML, conhecendo seus conceitos básicos e sua estrutura.
2. Avance para os módulos de HTML, aprendendo sobre as principais tags e como estruturar uma página web.
3. Continue com os fundamentos do CSS, aprendendo a estilizar e personalizar os elementos HTML.
4. Pratique os conhecimentos adquiridos por meio dos exemplos e atividades propostos.
5. Ao finalizar, consulte o arquivo `aprendizados.md` para conferir as reflexões e os conhecimentos adquiridos durante o curso.
